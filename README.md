# 🌻 Projeto Florescer

Um portal web comunitário desenvolvido com foco em impacto social para apoiar e dar visibilidade às iniciativas do **Coletivo das Flores**, grupo de estudantes da Esalq-USP. 

Este projeto foi idealizado e construído de forma colaborativa por um grupo de estudantes durante o curso técnico integrado em Informática no Instituto Federal de São Paulo (IFSP - Campus Piracicaba), unindo tecnologia e propósito para conectar a comunidade.

## 🎯 Objetivos do Portal
- Criar um espaço digital acessível e acolhedor para divulgar as ações do Coletivo das Flores.
- Facilitar a comunicação e o engajamento da comunidade com as causas do grupo.
- Aplicar conceitos práticos de design centrado no ser humano e usabilidade no desenvolvimento web.
